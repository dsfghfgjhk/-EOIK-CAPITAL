# $EOIK CAPITAL

해외주식·ETF 종목 탐색기. 종목 이름이나 티커를 넣으면 실적·뉴스·시세 페이지를 한 번에 모아 보여주는 레드 트레이딩 터미널.

## 기능
- 종목 269개(주식 + 해외 ETF), 카테고리 20개(SECTOR MAP), 한글 이름 검색
- 실적(재무제표·발표일·SEC 공시), 뉴스(구글·네이버·Yahoo), 시세·차트 링크
- 미국장 실시간 상태, 서울/뉴욕 시계, 휴장일·조기폐장 반영, 개장 카운트다운
- 최근 본 종목
